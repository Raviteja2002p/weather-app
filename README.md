# Weather App

A responsive weather application built using HTML, CSS and JavaScript.

## Features

- Search weather by city
- Display current temperature
- Display humidity
- Display wind speed
- Weather condition and icon
- Enter key support
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- REST API
- Fetch API
- JSON
- DOM Manipulation

## API

Open-Meteo API

## Purpose

This project was created to practice JavaScript API integration,
fetch requests, asynchronous programming and DOM manipulation.
